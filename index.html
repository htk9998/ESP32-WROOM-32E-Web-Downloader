ESP32-WROOM-32E Downloader

ESP32-WROOM-32E-N4 · 4MB Flash · esptool-js Web Flasher

사용 절차

보드를 데이터 케이블 로 PC 에 연결
전달받은 *.bin 파일 선택
Select COM Port 클릭 → 브라우저 팝업에서 포트 선택
Flash 버튼 클릭 → 자동 업데이트 진행
FW_Total_V*.bin (전체 → 0x0) 또는 FW_Update_*.bin / 앱만 (→ 0x10000) 업로드 가능.
(포트 미선택)
Serial 을 연 뒤 보드를 리셋 → 아래 로그에서 boot:0x3 (DOWNLOAD...) 가 보이면 다운로드 모드. boot:0x13 (SPI_FAST_FLASH_BOOT) 또는 앱 로그면 일반 부팅. Flash 전에는 Serial 을 닫아야 합니다.
브라우저 요구 사항
  • Chrome 89+, Edge 89+, Opera (WebSerial API)
  • Firefox / Safari 지원 안 함
  • HTTPS 또는 localhost 접속 필수 (GitHub Pages 는 자동 HTTPS)
